# Livewire to React Migration Plan

## Overview

Migrate the Cooperative Management System from Laravel Livewire 3 to a React SPA frontend. The backend (Laravel 12, Eloquent models, Spatie permissions, services) stays PHP — we replace the frontend layer entirely.

**Scale:** 36 Livewire components → React components, ~1 existing API endpoint → full REST API, 0 React code → React SPA.

---

## Decisions (Locked In)

| # | Decision | Choice |
|---|---|---|
| 1 | **React location** | Inside Laravel at `resources/react/` |
| 2 | **Auth strategy** | Laravel Sanctum SPA (cookie-based) |
| 3 | **Public pages** | Migrate everything to React (full SPA) |
| 4 | **State management** | React Context + React Query (no Zustand) |
| 5 | **Services decomposition** | Split into separate pages per service type |
| 6 | **Form library** | React Hook Form + Zod |
| 7 | **CSS** | Keep Tailwind v4 as-is |
| 8 | **UI components** | shadcn/ui |
| 9 | **Router** | React Router v7 |

## Key Technical Decisions

### Authentication
- Use **Laravel Sanctum** with cookie-based SPA auth
- React app on same domain (or proxied) to share cookies
- Axios interceptor adds `X-XSRF-TOKEN` header from cookie
- Login via `POST /api/login` returns user + permissions

### State Management
- **React Context** for global state: `AuthContext` (user, permissions, login/logout), `SidebarContext` (expand/collapse), `ThemeContext` (dark/light)
- **React Query** for server state: all API data fetching, caching, optimistic updates, refetch intervals
- Local component state (`useState`) for forms, modals, wizard steps

### Form Handling
- **React Hook Form** with **Zod** schemas for validation
- Zod schemas can be shared/derived from Laravel FormRequest rules
- Field-level validation on blur (matching current Livewire behavior)

### Routing
- **React Router v7** with nested layouts
- Role-based route guards via `ProtectedRoute` wrapper component
- URL-based section routing (replaces Livewire's `#[Url]` attribute)

### File Uploads
- Direct `FormData` uploads to API endpoints (no Livewire `WithFileUploads`)
- `react-dropzone` or shadcn Upload component for UI
- Progress tracking via Axios `onUploadProgress`

### Charts
- **react-chartjs-2** (wraps Chart.js) for reports and overview dashboards
- Same Chart.js dependency, just consumed differently

### PDF Export
- Keep **DomPDF** on Laravel side
- React sends request → Laravel generates PDF → returns download or blob
- Could also add client-side PDF generation for simple reports later

### Real-time Updates
- Initially use **polling** (React Query `refetchInterval`) for notifications, pending counts
- Could upgrade to WebSockets (Laravel Reverb + Pusher) later if needed
